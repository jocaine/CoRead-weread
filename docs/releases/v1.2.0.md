# CoRead 1.2.0

这一版把会意图变成可探索的书籍星系，也改进了共读如何找回旧讨论、利用原文和核查事实。

## 会意图：一本书，一个星系

- 书籍共享一个立体场景。拖动换角度，滚轮拉近，点轨道内飞近一本书，点外围空处回到全览。节点沿轨道缓慢公转；历史上连线越多的节点越靠内。
- 全览不铺连线。悬停可在底部读到完整观点，并看到直接关联；点选可打开详情。详情栏可以折叠，保留选中节点与关联。拉近后出现小字描述，被遮住的描述会变暗。
- 搜索覆盖全图的观点、相关说法和讨论问题。新书会找空位加入，已有星系记住位置。本轮高亮只显示回答实际使用的节点，旧记录仍可按旧命中清单显示；详情区分本轮范围内的连线和历史连线。

## 共读：更准确地找材料、回答原问题

- **在本机找旧讨论。** CoRead 会把当前问题和旧观点转换成可比较含义的数字，再在本机找相近讨论；没达到匹配门槛就不带入旧材料。你主动选的引用仍然可以使用。模型设置里可查看本地查找组件的状态。
- **复杂问题分步查证。** 回答先明确这轮要交付什么，再把需要查清的问题拆开，逐段读旧讨论、核对材料，最后合成正文。接着聊时会保留仍有用的材料，去掉本轮判定无关的材料。
- **有事实查证需求时可联网。** 配置的服务支持搜索时，回答会针对需要核查的事实找网页；点击正文里的来源标记，可查看对应引文和链接。搜不到材料时，讨论仍可继续。

## 阅读与对话

- 从引用可以回到阅读位置；把讨论归档成观点时，也会纳入这场讨论用过的划线原文。
- 改进了划线提问、引用预览、回复显示和停止回答的衔接，减少切书或停止后把迟到的回复混进当前对话的情况。

## 下载与启动

下载本页的 Windows 便携包，解压后双击 **Start-CoRead.vbs**，按包内 **README-FIRST.txt** 加载 Chrome 或 Edge 扩展。包内含运行环境，无需另装 Node.js；共读对话仍需配置兼容的模型服务。

从旧版升级，可以把新 ZIP 拖到旧包根目录的 **Update-CoRead.cmd** 上。更新完在浏览器扩展管理页点一次「重新加载」。
