## 1.2 CoRead 阅读器

这是我们的 PDF 阅读器。一般情况下我推荐您使用微信作为常用阅读器，但在以下情况您可能会需要使用Coread阅读器

1. 微信阅读无法识别当前pdf为电子书/电子书内容识别有误(如下图)
2. 需要翻译的外文书籍

<img src="C:\Users\lengdrug\AppData\Roaming\Typora\typora-user-images\image-20261015195426238.png" alt="image-20261015195426238" style="zoom: 67%;" />



它有三种打开方式，任选：

- 侧栏右上角 `⋯` → **📕 PDF 阅读器**（2026-11 起它就在这一层，点一下直接弹出选文件；
  没检测到在读的书时，侧栏**最底下也有一条**同样的入口）；
- 托盘图标上的**「打开 CoRead 阅读器」**，或**双击托盘图标**；
- 已经在阅读器里时，顶栏就有。

打开一份 PDF：

- 点顶栏的**「打开 PDF」**，或把 PDF **直接拖进窗口**；
- 读过一次的会留在**「书库」**里，下次点一下就行。

一本 PDF 打开之后，同时发生三件事：进书库、进「已读书籍」、成为侧栏的当前书。**不需要再"导入"一次。**

顶栏从左到右是：`打开 PDF`｜`书库`｜`目录`｜书名｜渲染状态｜页码｜缩放 `−` `＋`｜`框选翻译`｜`适宽`｜`译文`。

**「目录」**按书的情况给两种东西：有书签的 PDF 给**真书签**（学术书大多有，可以按层级点），没有书签的只剩页码滑杆，并明说这本没有目录。

如果 PDF 是**扫描件**（页面是图片、没有文字层），阅读器会直接告诉你，并指路「框选翻译」——因为那种页面里的文字选不中。

## 1.3 网页阅读源：B 站文章与中文马克思主义文库

有些东西既不在微信读书里，也不是一个文件，它就是**网页**。目前支持两类站点：

- **B 站**（bilibili.com）的专栏 / 图文；
- **中文马克思主义文库**（marxists.org/chinese）。

网页上的用法比前两条多一步，而且这一步不能跳：

1. 打开那篇文章，右侧侧栏底部会出现一张**「网页阅读源」**卡片，写着当前网址；
2. 点卡片上的**「加入一本书」**，把这一页归到某本书下；
3. 之后在页面上选中文字，浮出的浮标里会有**「📌 共读」**，点它 → 这段话成为侧栏的当前引用。

**为什么必须先"加入一本书"**：引用要有归属。侧栏得知道这条线是哪本书的，否则它在引用列表里无处安放，后面收口成的知识点也没有来路。没加入就点共读，它会明确告诉你"本页尚未加入任何书"。

# 第二章　划线、引用与翻译

这一章是你每天会用到的两个动作：**把一句话抓住**，和**把它读懂**。

## 2.1 抓一句话：划词 → 引用

三个平台的操作细节不同，但动作是同一个：**选中一段话，把它变成侧栏的"当前引用"**。

- 微信读书：划线即可（见 1.1）；
- 网页阅读源：选中 → 点「📌 共读」；
- CoRead 阅读器 / 教程书：选中 → 点浮标里的「共读」。

抓到手之后，侧栏上会有一张**引用卡**，上面是那句原文，下面这些按钮（鼠标移上去都有说明）：

| 按钮 | 作用 |
|---|---|
| 📍 | 在原书里定位这句话，滚过去并圈一下——**不重载整本书** |
| ↩ | 回到跳转之前的阅读位置 |
| **切换引用 ▸** | 打开引用抽屉：这本书的所有引用，可以搜索 |
| ▾ | 折叠 / 展开引用卡 |
| 🗑 | 删除这条引用（书页上的共读标记一并撤掉） |
| ✕ | 只是取消选中，不删 |

**引用是提问的起点。** 带着引用提问，它才知道你问的是哪一句；没有引用直接问，那是一次没有依托的闲聊。这两件事在它那里的处理完全不同——前者有归属的书、会被收口，后者不会。

> 🖼 **图 2-1** ｜ 建议内容：侧栏的引用卡特写，六个按钮都能看清。
>
> 🖼 **图 2-2** ｜ 建议内容：点开「切换引用 ▸」后的抽屉，里面有多条引用。

## 2.2 翻译：两种方式，对应两种页面

翻译只有一件事要判断：**这页上的字能不能被选中**。

| 情况 | 怎么做 | 为什么 |
|---|---|---|
| 有文字层（微信读书、网页、普通 PDF） | 选中 → **Alt+T**（划词翻译），或点浮标里的「翻译」 | 文字能选中，按选中的原文译 |
| 扫描件 / 图片型 PDF | **Alt+S**（框选翻译），或阅读器顶栏的「框选翻译」，在页面上拖一个框 | 没有文字可选，只能让模型**读图** |

Alt+S 那一下是"一次性的"：进入框选状态，拖完就退出，不会一直黏着。

译文的放置方式和别的工具不一样：**它按段落锚定在原文上**。所以改变窗口大小、缩放、关掉再打开，译文的位置都不跑偏——它不是飘在屏幕上的浮层，是贴在这一段原文旁边的。

想看这本书译过的全部段落：**在阅读器顶栏点「译文」**。那里能集中读、能重译、能删。那个面板挂在侧栏里（而不是在阅读器里再开一栏——否则就是两栏并排）。

> 🖼 **图 2-3** ｜ 建议内容：划词后浮标里「翻译」可见。
>
> 🖼 **图 2-4** ｜ 建议内容：一段外文旁边贴着中文译文（同一页），要能看出"译文贴在这一段旁边"。
>
> 🖼 **图 2-5** ｜ 建议内容：阅读器里点顶栏「译文」后，侧栏里的译文对照面板（列出多条译文）。

## 2.3 这些东西存在哪

一句话：**都记在那本书下面，书与书之间互不串味。**

- 你的引用、讨论、译文，都按书 ID 存放，与别的书隔离；
- 所以「切换引用」里看到的永远是**当前这本书**的引用；
- 也因此，读完一本书再打开另一本，消息区不会残留上一本的内容。

# 第三章　上下文：它为什么记得你

前两章是操作。这一章讲的是：这些东西连起来之后，为什么它开始不像一个工具。

## 3.1 一场讨论怎么变成一个知识点

你在读一本书，划线、提问、它回答、你反驳。这一来一回如果**聊透了**，它会做一件事：把这场讨论**切分、归纳**，做成一个**知识点节点**，再把这场讨论里引用过的旧节点连成边。

这个动作叫**收口**——像把一张敞开的袋子收起来、扎上口。

什么时候收：

- **它自己判断**。聊透了就收，没聊透就不收，不用你管；
- **手动**：这本书快读完时，在输入框里敲 `/收口`，它把这本书记下的讨论整理一遍；
- **归档一场自由对话时**，它会问你"要不要收口进会意图"（默认勾上）。

收下来的节点长在**会意图**里——侧栏右上角那个 **`◎`**。图上每个点是一次收口，每条连线是话题之间的来路。

边上其实有两种，值得分清：

- **引用边**：这场讨论当初引用了谁。**收口那一刻定格，之后不再改**；
- **衍生边**：后来谁又引用了这个点。**会随着图越铺越大而越来越乱**。

> 🖼 **图 3-1** ｜ 建议内容：会意图全屏视图，能看到若干节点与连线。要证明的是"讨论真的长成了图"。
>
> 🖼 **图 3-2** ｜ 建议内容：点开一个节点后的详情（知识点表述 + 相关说法）。要证明的是"一个点里到底存了什么"。

## 3.2 换个说法，也认得出来

收口把讨论存下来了。但存下来的东西，如果连你自己都记不得聊过，那等于没存。

所以这里真正的能力是**取**：隔了一段时间、换了一本书、换一种说法再提起来，它能不能认出这是同一件事。

认出来的表现很具体：**对话命中旧知识点时，会意图上相关的那条路径自动高亮，其余压暗**。那一下，就是"你的那条线"被接上了。

> 🖼 **图 3-3** ｜ 建议内容：一次命中发生时的会意图——一条路径亮着、其余压暗。这是这一章最重要的一张图。

为什么只走"来路"、不跟着"去路"跑：去路是"后来谁引用了它"，会随着图变大而发散；跟着去路走，讨论容易被拽到跟你此刻的问题毫无关系的老话题上。

## 3.3 两个长期记忆：profile 与 soul

自由模式里（读书/自由开关拨到「自由」）的讨论是**临时**的：它不挂在一本书上，默认也不留下长期痕迹。

但一场自由对话聊完、点 **`⤓ 归档`** 时，它会问你两个问题，**默认都勾上**：

- **保存记忆** —— 这场对话里关于"你"的部分，被合并进两份长期记忆；
- **收口进会意图** —— 按读书模式那套收口流程，变成知识点节点。

（归档 = 结束并清理：对话和消息一并删除，列表里只留一行记录告诉你产物去了哪。不想留痕就把两个勾都取消。）

那两份长期记忆，一句话区分：

| | 是什么 | 回答的问题 |
|---|---|---|
| **profile**（阅读画像） | 它对你的理解：你在读什么、关心什么、哪些问题反复出现 | **你是谁** |
| **soul**（自画像） | 它该怎么和你相处：它采取的立场、与你的共识与分歧、你对它的要求 | **我该怎么跟你说话** |

这两份东西不是聊天记录，是**被反复改写的两页纸**——每一场选择"保存记忆"的对话，都会让它们更准一点；也正因如此，它们里面**没有你的原话**，只有它消化之后的理解。
