CoRead —— 一分钟上手
============================================================

【放哪里】很重要，先看这条

  不要把整个文件夹放进 C:\Program Files！
  那里受系统保护，程序写不进自己的数据，会启动失败。

  放到这些地方都可以：
      D:\CoRead
      C:\Users\你的用户名\CoRead
      桌面、文档、其他盘的普通文件夹

  （已经在 Program Files 里了？整包剪切出来就行。）


【怎么用】三步

  第 1 步  双击  Start-CoRead.vbs（就在这个文件夹里）

           （是个 .vbs 文件，不是 .bat。Windows 自带的脚本，作用就是"隐藏启动"——
            所以双击它不会闪出黑窗口。杀软若提示，允许即可。）

           右下角托盘会出现一个图标。右键它可以：
             打开 CoRead 阅读器 / 阅读器用哪个浏览器 / 打开微信读书 /
             装浏览器插件 / 打开数据文件夹 / 查看日志 / 退出 CoRead

           （双击托盘图标 = 打开 CoRead 阅读器，就是推荐的那一个。）

  第 2 步  装浏览器插件

           这插件是"未打包的扩展"，靠浏览器直接读文件夹来装。三步：

           ① 打开浏览器的「扩展程序」管理页
              最省事的入口：地址栏右边那个拼图块形状的图标
              →「管理扩展程序」。
              找不到这个图标，就走菜单：右上角（三个点 或 三条横线）
              →「扩展程序」。
              怎么知道找对了：这一页会列出已装的扩展，并且有一个
              「开发者模式」开关。

              想直接输地址也行，但只有这两种浏览器能这么写：
                Chrome   chrome://extensions/
                Edge     edge://extensions/
              其余 Chrome 内核浏览器的地址各不相同（Brave、Vivaldi、
              360 极速、QQ、猎豹……），用上面的图标或菜单最稳。

           ② 打开「开发者模式」（一般在页面右上角）

           ③ 点「加载已解压的扩展程序」
              各浏览器的措辞不一样（Edge 上就不叫这个名字），认准它的
              作用：让你选一个本地文件夹。选中本文件夹里的  extension
              目录 —— 就是旁边那个。

           省事的做法：右键托盘图标 →「装浏览器插件」。
           它会把 extension 目录的完整路径复制到剪贴板，并在资源管理器里
           把这个目录指给你看，同时弹出一个三步说明的窗口。这样在③弹出
           选择框后粘贴（Ctrl+V）+ 回车就能直接跳过去，不用自己一层层翻。
           说明窗口会一直浮在最上面（方便你一边看一边在浏览器里操作），
           里面有一个「复制路径」按钮 —— 剪贴板中途被别人盖掉了就再点一下。
           （把文件夹拖到扩展页上是装不了的，所以只能这样选目录。）

           注意：这套装法适用于 Chrome 内核的浏览器。Firefox 的侧栏是
           另一套机制，CoRead 的侧栏用不了它，所以 Firefox 暂时装不了。

  第 3 步  填模型 API Key

           双击右下角托盘图标，会打开 CoRead 自己的阅读器（推荐先看它一眼：
           在里面能打开 PDF、划词翻译，译文对照挂在侧栏里，不用先去别的网站）。
           点侧栏右上角「⋯」→「模型 API 配置」，填入 API 地址、
           API Key、模型名，保存即生效。

           想在微信读书里共读也一样：右键托盘图标 →「打开微信读书」，
           右侧会出现同一个 CoRead 侧栏。两者共用同一套配置，记录不分开。

           （阅读器只会在**装着 CoRead 插件**的浏览器里打开。如果你在 Chrome 与
             Edge 里都装了插件，托盘会问你一次用哪个，并把你的选择记下来；
             想换：右键托盘图标 →「阅读器用哪个浏览器」。两边的阅读进度是
             各存各的，所以这个选择会影响你看到的进度。）


【你的数据在哪】

  都在  data  文件夹里（就是旁边那个，托盘右键「打开数据文件夹」也能跳过去）：

      data\config\     设置：API 地址、模型名、密钥（含密钥，别外发）
      data\profile\    阅读画像、价值观侧写、知识图谱
      data\sessions\   聊天记录、讨论进度
      data\reading\    划线标注、书库缓存（你读过的章节原文）
      data\runtime\    运行状态（可以随时删，程序会自己重建；
                       里面那份 extension-id 是浏览器插件的编号，
                       托盘靠它才能打开 CoRead 阅读器）
      data\toolbox\    翻译记录
  备份：复制  data  这一个文件夹，就是完整备份。
  搬家：把 data 文件夹拷到新电脑的同一个位置（和 internal 同级）。
  彻底删除：先退出 CoRead，再删掉整个程序文件夹。
  哪一格能删、哪一格不能删：data\README.txt 里写清楚了。


【怎么升级到新版本】

  1. 先从托盘图标退出 CoRead（别在程序运行时覆盖文件）。
  2. 把新版本的 zip 解压到**原来那个文件夹**上，提示"是否替换"就选替换。
  3. 重新双击  Start-CoRead.vbs（包根那个）。

  你的记录不会被动：包里**不含任何 data\ 下的文件**（只有空的目录壳），
  所以覆盖的只是程序本身，data\ 是你原来的那份，一个字都不会变。
  ——这条是打包时强制校验的：data\ 各格里只要出现一个文件，打包就会中止。

  想更保险就先备份：把 data 文件夹复制一份再升级。
  升级前请务必退出程序：程序正在跑的时候覆盖文件，可能覆盖到一半失败。


【出问题了】

  双击 Start-CoRead.vbs 没反应、也没弹提示
      → 先确认包根那个 Start-CoRead.vbs 还在（不是被移走了）
      → 再看 logs\ 里的 tray.log（有错会写在这儿）
      → 系统若提示"无法打开此文件"，说明这台机器禁用了 VBScript 组件：
        设置 → 系统 → 可选功能 → 添加功能 → 搜 VBScript 装上

  看到"无法验证发布者"的安全警告
      → 双击 internal\unblock.bat，之后不再弹。

  杀毒软件报警（火绒/360/Defender）
      → 误报。本程序没买数字签名证书。在弹窗里选「允许」并记住；
        火绒可以把它加进「信任区」。原因和自查方法见详细说明。

  双击后托盘没出现图标
      → 打开 logs\ 看日志；或先跑 internal\stop.bat 再重试
        （常见原因是端口被上一份没关干净的进程占着）。

  更详细的排查：internal\instructions-zh.txt


【其他文件】

  data\         你的全部数据。要备份就复制它，别的都不用管。

  Start-CoRead.vbs  启动入口，双击它（就在这个文件夹里）。
                想核对它做了什么可以右键 →「编辑」，纯文本、没有编译过的二进制。

  internal\     程序本体（Node 运行环境、引擎、接收端、说明书、排障脚本）
                启动入口**不在这一格里**，就在包根、和本文件并排。
                想核对程序做了什么可以放心看——里面的代码都是可读的
                纯文本 JavaScript，没有编译过的二进制。
                这里**不放你的数据**，程序升级覆盖它不会碰到你的记录。

  builtin\      空目录（旧版本在这里放内置图谱，现在不用了）。不用管。

  logs\         运行日志，只在排查问题时才需要看。
