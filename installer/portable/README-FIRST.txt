CoRead —— 一分钟上手
============================================================

【先看这条】别把这个文件夹放进 C:\Program Files —— 那里系统保护，程序写不进
自己的数据，会启动失败。放桌面、文档、D:\CoRead 这类普通文件夹都行。

【三步】

  1. 双击  Start-CoRead.vbs      右下角出现托盘图标就是成功了。
     杀软提示的话选「允许」。右键那个图标，常用的都在里面：
     打开阅读器 / 打开微信读书 / 装浏览器插件 / 打开数据文件夹 / 退出 CoRead。
     （双击图标 = 打开 CoRead 阅读器。）

  2. 装浏览器插件
     右键托盘图标 →「装浏览器插件」，照它弹出的说明做就行。
     Chrome 内核的浏览器都行；Firefox 用不了。

  3. 填模型 API Key
     双击托盘图标打开阅读器，点侧栏右上角「⋯」→「模型 API 配置」，
     把 API 地址、Key、模型名填上，保存即生效。
     地址和模型可以直接从预设里选（DeepSeek 已预填）；还没有 Key 的话，
     弹窗里「没有 API Key？去 DeepSeek 申请」那一条会带你过去。
     想在微信读书里共读：右键托盘图标 →「打开微信读书」，右边是同一个
     侧栏，两边配置共用、记录不分开。

  书库里自带一本《CoRead 使用教程》（五页）：双击托盘图标打开阅读器，
  在「书库」里点它就行。从书库里删掉之后，它不会再回来。

【你的数据】

  全在  data  这一个文件夹里（托盘右键「打开数据文件夹」也能跳过去）。
  备份 = 复制它，没有别的要拷的。  换电脑 = 拷到新包的同一个位置。
  彻底删除 = 先退出 CoRead，再删掉整个程序文件夹。

【升级】
  下一版起：把新下载的 zip 拖到包根的  Update-CoRead.cmd  上就行（也可以双击它、
  再在弹出的框里选 zip）。它会先让 CoRead 停下来，然后把程序文件整体换掉 ——
  旧版本留下的文件会一并清掉，你的 data 文件夹一个字节都不动。
  更新完记得去浏览器扩展页点一次「重新加载」，不然界面还是旧的。

  如果这个文件夹里还没有 Update-CoRead.cmd（1.0.1 之前的老包），那这次请照旧：
  先退出 CoRead → 把新版本解压到原来那个文件夹上、选替换 → 重新双击。
  更新完同样要去扩展页点一次「重新加载」。

【出问题了】

  双击没反应         → 先看托盘右键菜单里的「查看日志」
  杀软报警           → 误报（程序没买数字签名证书），选「允许」就行

  还搞不定：internal\instructions-zh.txt（排查手册）
