CoRead —— 一分钟上手
============================================================

【先看这条】别把这个文件夹放进 C:\Program Files —— 那里系统保护，程序写不进
自己的数据，会启动失败。放桌面、文档、D:\CoRead 这类普通文件夹都行。

【三步】

  1. 双击  Start-CoRead.vbs      右下角出现托盘图标就是成功了。
     杀软提示的话选「允许」。右键那个图标，常用的都在里面：
     打开阅读器 / 打开微信读书 / 装浏览器插件 / 打开数据文件夹 / 退出 CoRead。
     （双击图标 = 打开 CoRead 阅读器。）

  2. 装浏览器插件
     右键托盘图标 →「装浏览器插件」，照它弹出的说明做就行。
     Chrome 内核的浏览器都行；Firefox 用不了。

  3. 填模型 API Key
     双击托盘图标打开阅读器，点侧栏右上角「⋯」→「模型 API 配置」，
     把 API 地址、Key、模型名填上，保存即生效。
     想在微信读书里共读：右键托盘图标 →「打开微信读书」，右边是同一个
     侧栏，两边配置共用、记录不分开。

【你的数据】

  全在  data  这一个文件夹里（托盘右键「打开数据文件夹」也能跳过去）。
  备份 = 复制它，没有别的要拷的。  换电脑 = 拷到新包的同一个位置。
  彻底删除 = 先退出 CoRead，再删掉整个程序文件夹。

【升级】先退出 CoRead → 把新版本解压到原来那个文件夹上、选替换 → 重新双击。
  你的记录不会被碰。

【出问题了】

  双击没反应         → 先看托盘右键菜单里的「查看日志」
  杀软报警           → 误报（程序没买数字签名证书），选「允许」就行
